## 🧭 How I work

- **Model first.** I build star schemas, document every measure, and save Power BI projects as **PBIP** (TMDL + PBIR) so they live in version control.
- **Check the numbers.** DAX measures are tested against an independent answer key, and statistical models are checked for assumptions, confidence intervals, cross-validation and data leakage.
- **Reproducible by default.** Each repository has a README, a `requirements.txt`, sample data and tests that run without credentials.
- **Privacy matters.** Work data is anonymized before it is published, with Python + Faker keeping every relationship consistent.
